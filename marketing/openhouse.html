Parent FAQ

How much does it cost?

The program fee is $8,000 per year. If the number is a stretch, email team@shftrobotics.com. We would rather talk it through than have you stay away.

How much time does it take?

A few sessions a week, more in build season. We are upfront so families can plan.

Is it safe?

Yes. Trained mentors, safety rules, supervised use of every tool.

Zero experience, is that okay?

Yes. No experience required. The program is built for beginners. We teach everything.

Does it help with college?

Students leave with real artifacts: CAD models, code they wrote, and a robot they can point to in an interview. We make no admissions promises; the work speaks for itself.

Who runs it?

Malhar Soni, Team Director and Head Coach, and Noeen Kashif, Voluntary Mentor. They mentor FRC Team 7558 ALT-F4 in Toronto: 35th in Canada in 2019 to 3rd in 2026.

Parent commitment?

Optional. Rides help, and any skill you want to share is welcome.

What if it is not for them?

They try it, no strings. If not, they leave with new skills.
