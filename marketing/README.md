# SHFT Recruitment Marketing Kit

Everything you need to recruit new high-school students to SHFT this summer into September. Built for a non-coder. You can run the whole campaign from the files in this folder.

**Brand in one line:** lime bolt on black. Slogan: "Shift the standard." The goal of every piece here is to get a student to follow, sign up, and show up to Info Night.

---

## Start here (this week)

Three moves get the funnel live. Do them in order.

1. **Fill in your facts.** Open `TODO-from-you.md` in this folder. It is one checklist of every blank the whole kit needs (Info Night date and place, your contact email, your signup link, tryout dates, team number, city). Decide these now. Everything else waits on them.
2. **Build the signup form and the social account.** Make the Google Form using `events/signup-form.md` (copy the fields exactly). Set up `@shftrobotics` using `social/profile.md` (paste the bio, set the link, upload the highlight covers). This is the spine of the campaign.
3. **Read the plan and pick a budget.** Open `PLAN.md`. It is the 8-week game plan with a week-by-week calendar. Pick a budget tier ($0, ~$150, or ~$500) from section 7. Then start posting from `social/` and printing from `print/`.

That is it. Form built, account live, plan picked. The rest of this kit is the content to fill those channels.

## How to print a flyer or poster

The print files are web pages that look like a finished flyer. You turn them into a PDF using your browser. No design software needed.

1. **Open the file in a browser.** In Finder, find the file (for example `print/flyer-letter.html`), right-click, Open With, Chrome. It opens looking like the finished flyer.
2. **Fill in the blanks first.** If you see things like `[FILL: date]` on the page, you need to edit them. Open the same `.html` file in a plain text editor (TextEdit in plain-text mode, or VS Code), use Find to locate each `[FILL: ...]`, type the real value, save, then refresh the browser. Or print it with the blanks and write them in by hand if you are in a rush.
3. **Print to PDF.** With the flyer open in Chrome, press **Cmd-P**.
   - **Destination:** Save as PDF.
   - **Margins:** None.
   - **Background graphics:** On. (This is the setting that keeps the black background and lime color. If you skip it, you get a white page.)
   - **Paper size:** the flyer is built for Letter (8.5 x 11). The poster is Tabloid (11 x 17). The page already sets this, so leave paper size on Default or match it.
4. **Save, then send to a printer.** You now have a clean PDF. Print it at home, a library, or a print shop. For the big poster, a print shop on real 11 x 17 paper looks best.

**The QR code on the flyers is a placeholder.** Generate a real QR code (any free QR generator) pointed at your signup link, and drop it in. The tracking link to use is in `ads/targeting-and-tracking.md`.

## How to use a social template

The social and ad templates are web pages that render a perfect on-brand graphic. You edit one or two lines, then screenshot it.

1. **Open the file in a browser.** Right-click `social/story-template.html` (or `post-template.html`, or `ads/ad-creative.html`), Open With, Chrome.
2. **Swap the words.** Open the same `.html` file in a text editor. Near the top you will find the headline, subline, and CTA lines. Change the words to what you want. Swap any `[FILL: ...]`. Save, refresh the browser.
3. **Screenshot the frame at the right size.**
   - The **story** template is 1080 x 1920 (tall, for Stories and TikTok).
   - The **post** and **ad** templates are 1080 x 1080 (square, for the feed).
   - Easiest way: take a normal screenshot of just the lime-edged frame and crop to it. For a pixel-perfect export, ask for help capturing at exact size, but a clean crop is fine for posting.
4. **Post it.** Upload the image to Instagram or TikTok. Pair it with a caption from `social/captions.md`.

That is the whole loop: open, swap the words, screenshot, post. Same idea for every HTML file in the kit.

## A few rules that keep it on-brand

- **Lime on black.** Never lime on grey, never the bolt on a lime field. Restraint is the point.
- **One ask per post or poster.** Follow, or sign up, or come to Info Night. Never three at once.
- **No em dashes in any copy.** Short, confident sentences. The kit already follows this. Keep it that way when you edit.
- **Do not redraw the logo.** Use the real files. For big merch, get true vectors first (`merch/vector-plan.md`).
